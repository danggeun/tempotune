> 원칙: 고치기 전에 읽는다. 지금 화면의 모든 디테일은 v1 커밋 50개 안에서 내려진 결정이다.

## 1. 사용 상황 — 이 앱은 어디에 놓여 있는가

| 순간 | 폰의 위치 | 손 | 시선 거리 | 화면에 바라는 것 |
|---|---|---|---|---|
| **조율** (세션 첫 1–2분) | 보면대 위 또는 무릎 | 한 손은 악기, 한 손은 펙/미세조정 | 30–50 cm | 음이름 + 얼마나 벗어났는지, 즉각 반응 |
| **연습 중 힐끗** (세션의 90%) | 보면대 위, 팔 길이 밖 | 둘 다 악기 | 60–90 cm | 박자(눈으로 확인), 음정 트레이스가 초록 띠 안에 있나. **조작 없음** |
| **조작** (BPM 바꾸기, REC 켜기) | 그대로 두고 손 뻗음 | 한 손, 활을 든 채 | 40–60 cm | 큰 타겟, 한 번의 탭, 오조작 시 되돌리기 |
| **되듣기** (연습 후) | 손에 들고 앉아서 | 둘 다 자유 | 25–35 cm | 정밀 조작 OK, 정보 밀도 OK |

→ 메인 화면(튜너·메트로놈)은 **원거리·힐끗·한 손** 화면이고, 메뉴·설정·편집기는 **근거리·앉아서·두 손** 화면이다. 같은 앱이지만 두 종류의 화면이며, 기준을 따로 적용해야 한다. 현재 디자인은 이미 이 구분을 따르고 있다(튜너 음이름 96px 급, 편집기 텍스트 11–13px). 이 구분을 흐리는 변경은 하지 않는다.

### 3.3 확인했고 **바꾸지 않는** 것 (의도 존중)

- 튜너 cents 숫자 20 px: 조율 순간은 근거리. 트레이스와 초록 띠가 원거리 정보. 유지.
- 벗어남에 색 없음(흰 트레이스·흰 바늘): 의도. 유지.
- 태블릿 메트로 카드 아래 빈 공간: "추가하지 않는다". 유지.
- 메트로 접힘 타이밍, 라이트 팔레트, 섹션 제목, 단계 버튼 틴트: 유지.
- 파형 확대(Phase 4 리뷰 제안): 더블탭은 발견되지 않고, 확대 상태는 언어 밖의 UI 를 부른다. **실사용 후** 판단. 보류.
- 북마크 한 단어 라벨: 입력 UI(prompt)가 앱 안에 하나 더 생긴다. 보류.
- 시스템 글꼴 크기 대응(px → rem): 튜너 레이아웃이 px 로 고정된 건 의도로 보임(카드 안 배치). 전환은 큰 변경. **사용자 결정 필요**.
- 햅틱: 취향. **사용자 결정 필요**.

- **W1 (합산 2위)** — 연주자 1위. "앱을 켰을 때의 검은 무대와 이어진다", "초록을 한 줄로만 써서 규칙을 지킨다". 브랜드 심사의 유일한 감점 사유는 **"가로 초록 막대 = 밑줄·로딩바로 읽힌다"** 였는데, 심사는 정제 전(단색 막대) 안을 본 것이고 현재 구현은 게이지 형태(중앙 60 % 실선 + 양 끝 .38)로 그 오독을 해소했다. 즉 W1 의 감점 근거는 이미 사라진 상태다.
- 연주자가 따로 요청한 하이브리드: S3 의 초록 현을 **살짝 휘게** 해 "켜져 있다" 가 아니라 "울리고 있다" 를 말하게 하는 것. 후속 후보로 기록.

기각 사유 기록: 흰 바탕 전반(홈 화면 증발) · 초록 바탕(브랜드 충돌 + 규칙 위반) · 심볼 단독(이름 각인 0, 48 px 오독) · 한글 '라'(한국 특정, 사용자 기각).
`scripts/gen-icons.mjs` 가 세 콘셉트를 모두 렌더한다: `--concept bar`(W1) · `--concept o`(C2) · `--concept ra`(1차 후보, 기록용).

### 2라운드 — 연주자 제안 하이브리드 (휘어 울리는 현)
연주자 요청("초록 현이 살짝 휘어 '울리고 있다'를 말하게, 또는 현이 Go 옆·뒤를 지나가게")을 6안으로 렌더해 두 심사가 다시 봤다.

| 안 | 결과 |
|---|---|
| H1 현 4개 · 초록 현 살짝 휨 | 48 px 에서 휨이 완전히 소멸 — S3 와 구분 불가 |
| H2 굵게 + 크게 휨 | 하이브리드 중 유일하게 큰 화면에서 의미가 삼. 다만 한 방향 활 모양이라 **괄호 `)`** 로 읽힘 |
| H3 진동 방추형 | 물리적으로는 가장 정확하지만 **초록 나뭇잎**(식물·에코 앱)으로 읽힘. 두 심사 모두 즉시 탈락 |
| H4 Go 옆 초록 현 | **텍스트 커서** — 하필 Go 언어 연상까지. 글자와 선이 관계 없이 '붙여놓은' 상태 |
| H5 Go 관통 | o 가 잘려 `Gd`·`GØ` 로 보임 — **워드마크 훼손** |
| H6 현 + 아래 Go | 48 px 에서 Go 가 얼룩. 아이콘에 요소는 하나만 |

**두 심사 모두 1라운드 선택을 유지했다.** 연주자: "휨은 큰 화면에서만 성공했다. 48 px 에서 현 4개는 연주자인 나조차 바코드로 본다 — 이건 다듬어서 될 문제가 아니라 해상도 예산 문제다. W1." 마케터: "이번 라운드는 연주자의 요청이 아이콘이라는 매체와 맞지 않는다는 걸 증명했다. C2." 두 사람이 독립적으로 같은 후속을 제안: **H2 는 아이콘이 아니라 스플래시·앱 내 헤더·굿즈용 세컨더리 마크로 남길 것**(큰 크기에서는 휨이 제 값을 한다).

각자 요구한 출시 조건은 둘 다 반영했다.
- W1: 초록 띠 가운데에 **흰 바늘** 추가 → 트랙 + 허용 띠 + 바늘 = 인앱 게이지의 '맞음' 순간. 브랜드 심사의 유일한 감점 사유였던 "로딩바로 읽힘"이 형태로 끊겼다.
- C2: 세리프 헤어라인이 작은 크기에서 끊기지 않게 **아이콘 전용 광학 보정**(본문 워드마크는 그대로).

최종 선택(W1 / C2)은 사용자 결정. 두 콘셉트 모두 `scripts/gen-icons.mjs` 에 있어 교체는 명령 한 줄이다.

### 최종 확정 — W1, 스펙 수렴 (2026-09-06)
사용자 확정: **W1**. ("C2 는 흰 G / 초록 o 의 명암 반전이 거슬린다. W1 인데, 띠가 가운데만 진하고 양옆이 옅은 게 거슬린다.")

### 9.6 락업 간격 재조정 — 3.8 % → 5.3 % (2026-09-06)

사용자 지적: "글자와 띠가 너무 붙어 답답하다. 원본은 더 띄워져 있었다."

**기록을 다시 읽은 결과 지적이 타당했다.** 3.8 %는 브랜드 심사가 준 값이지만, 그 심사가 본 후보는 간격 1.0 %였고 처방은 "**3.5 % 이상으로 띄워라**"라는 **하한**이었다. 최적값을 위로 탐색한 적이 없다. 그리고 열별 실측 결과 간격은 균일하지 않았다 — 이탤릭 'G'의 긴 꼬리 때문에 **꼬리 밑만 3.91 %**, 'o' 아래는 4.49 %. 눈은 가장 좁은 곳으로 전체를 판단하므로 실제보다 더 붙어 보였다.

간격 5안(3.8/4.4/5.0/5.6/6.2 %) × 띠 폭 3안(68/75/82 %)을 렌더해 두 심사(브랜드 디자이너 · 스토어 마케터)가 독립적으로 다시 봤다.

| | 브랜드 디자이너 | 스토어 마케터 |
|---|---|---|
| 간격 | **5.3 %** (꼬리 밑 실측 5.4 % 이상이어야 압박이 풀림. 6 % 넘으면 두 물체로 분리) | **5.0 %** (3.8→5.0 은 이득, 그 위는 손해) |
| 띠 폭 | **75 % 고수** — 82 %는 48 px 에서 띠 끝이 글자 폭선에 근접해 '룰(rule)'로 읽힘 | **82 %** — 초록 면적이 커져 스토어 그리드 단서가 강해짐 |

띠 폭에서 갈린 판단은 **48 px 다운샘플 초록 픽셀 실측으로 결정**했다.

- 간격만 3.8 → 5.3 %: 48 px 초록 픽셀 **39 → 52 (+33 %)**. 붙어 있던 글자 밑변과 띠 윗변의 안티에일리어싱이 분리되면서 띠가 깨끗한 초록으로 살아난다.
- 띠 폭 75 → 82 %(간격 동일): 52 → 57 (**+10 %**)
즉 마케터가 원한 '초록 존재감'의 **대부분은 간격 변경만으로 이미 확보**된다. 남은 10 %를 얻자고 두 심사가 두 라운드에 걸쳐 수렴시킨 75 %를 다시 열 이유가 없다 — 게다가 브랜드 심사는 82 %에서 밑줄 오독이 재발한다고 본다. **간격만 바꾸고 가로(띠 폭)는 건드리지 않는다.**

두 심사가 공통으로 경고한 "간격을 키우면 마크가 아래로 쏠린다"는 2패스 광학 정렬이 자동 흡수했다 — 조정 후 마크 광학 중심 x +0.6 px / y −11.9 px(리프트 목표 −12.3), 조정 전과 동일.

**조정 후 실측**: 꼬리 밑 최소 간격 **5.37 %** · 중앙값 6.01 % · 띠 아래 여백 30.76 %(간격보다 커서 결속 유지) · 띠 ↔ 글자 중심 +0.5 px · 바늘 ↔ 띠 중심 0.0 px · 초록 좌우 팔 198.5 / 198.5 px · 외접원 0.275 S(원형 마스크 안전 0.5 S).


남긴 후속: 하이브리드 H2(휘어 울리는 현)는 큰 크기에서 값을 하므로 **스플래시·앱 내 헤더·굿즈용 세컨더리 마크** 후보로 보관. 알림 아이콘(24 px 모노)은 워드마크가 아니라 바늘만 남긴 별도 심볼이 필요 — 실기기 단계에서 재검토.
