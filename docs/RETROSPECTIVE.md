# Go practice v1 → v2 — 무엇이 어떻게 달라졌나 (마무리 정리)

2026-09-05 · 커밋 `fd56de1`(v1) → `v2.0.0`. 실사용 전 마지막 정리. 각 항목은 **원래 어땠는지 → 지금 어떤지 → 실제로 어떻게 보이거나 느껴지는지**로 적었다. 전/후 화면은 `v1_vs_v2_*.png` 3장.

---

## 총평

v1은 "동작하는 프로토타입"이었고, 좋은 판단이 이미 안에 있었다 — 검정 무대 위의 큰 음이름, 초록은 '맞음' 하나, 빨강 하나, 확인 대화상자 없는 텍스트 버튼. v2는 그 판단을 **하나도 바꾸지 않고** 세 가지를 했다.

1. **틀린 것을 고쳤다.** 사용자가 겪었을 결함이 실제로 있었다: 기준음을 415로 두면 모든 음이 반음 틀리게 표시됐고, 메트로놈을 빠르게 틀면 튜너가 멈췄고, 녹음을 정지 직후 다시 누르면 앞 녹음이 깨질 수 있었고, 파일명을 바꿔도 재시작하면 돌아왔다. 전부 자동 테스트가 재현하고 지금은 통과한다.
2. **엔진을 제품 수준으로 바꿨다.** 메인 스레드에서 돌던 튜너를 워클릿→워커 파이프라인으로, setTimeout 메트로놈을 샘플 정확도 워클릿으로, 온라인 모델(YAMNet)을 오프라인 신호처리로. 화면이 꺼져도, 오프라인이어도, 전화가 와도 동작이 정의돼 있다.
3. **디자인을 '제각각'에서 '체계'로.** 색·크기·굵기·간격이 토큰 한 벌에서 나오고, 20단계였던 글자 크기가 11단계로, 버튼 굵기가 전부 700이던 것이 주행동만 700으로. 겉보기는 비슷한데 한눈에 덜 피곤하다 — 그게 목표였다.

그리고 **사람 없이 확신하는 방법**이 생겼다: 합성 신호 39개 벤치마크, WAV를 마이크로 주입하는 e2e 38개, 스크린샷 12장 픽셀 비교, 단위 테스트 73개, CI. 앞으로 무엇을 바꾸든 "깨졌는지"를 기계가 먼저 말해준다.

솔직한 한계: 실기기에서 아직 안 본 것이 있다(Android 15 상태바, 아이콘 실제 모양, 권한 두 번 거부 복구, 통화 복구). 말소리는 대부분 연주 시간에 포함된다(음악 우선 결정). 이건 실사용 피드백 라운드의 몫이다.

## 숫자로 보는 변화

| 지표 | v1 | v2 |
|---|---|---|

| 저음 한계 | 80 Hz (첼로 C2 65 Hz 불안정) | 40 Hz (콘트라베이스 E1) + 옥타브 교정 |

| 버튼 굵기 700 비율 | 전부 | 주행동·섹션 제목·원거리 캡스만 |
| 편집기 한 화면의 빨강 | 12곳 | 6곳 |
| 터치 타겟 < 44 px | 10여 곳 (REC 28, 접기 34, 뒤로 26, ‹› 23, 수정 14…) | 0 |
| 다크 모드 토스트 대비 | 1.05:1 (안 보임) | 면+테두리 |
| 조용한 실패 (오류인데 아무 표시 없음) | 설정 저장·IDB·meta·wake lock 등 | 0 — 전부 토스트 |
| 아이콘 | 서체·색이 앱과 다른 "GO" | 튜너의 '맞음' 장면 '라' |

## 항목별 변화

### 1. 튜너 (음정 감지)

| 항목 | v1 (원래) | v2 (지금) | 어떻게 보이나 / 평가 |
|---|---|---|---|
| 감지 알고리즘 | YIN 직접 계산 O(N²) + FFT 교차검증, 메인 스레드 | FFT 기반 YIN O(N log N) + 신뢰도, 스펙트럼 배음 비교로 옥타브 교정 | 같은 정확도(bias < 1 ¢)를 5배 싼 비용으로. 첼로 C2·베이스 E1이 도2·미1로 정확히 잡힘 |
| 스레드 | AnalyserNode를 rAF로 폴링 → 화면 부하와 분석이 서로 밀림 | AudioWorklet 캡처 → Worker 분석 → 메인은 rAF에 최신값만 그림 | 메뉴를 열어도, 파형을 그려도 바늘이 끊기지 않음 |
| 안정화 | 단순 EMA 평활 (느림/보통/빠름) | 신뢰도 가중 중앙값 + 음이름 히스테리시스 + 비브라토 인식 적응 평활 | 비브라토 중에도 음이름이 깜빡이지 않고, 글리산도는 따라감 |
| **기준음 보정** | A=440 격자에서 이름을 정하고 cents만 보정 → **|오프셋| > 50 ¢(427 미만·453 초과)에서 이웃 반음으로 표시** | 트래커 앞에서 정규화 | 바로크 415에서 415 Hz = 라 0 ¢ (이전: 솔♯ +100 ¢). 광고하던 기능이 틀렸던 것 |
| 메트로놈과 동시 사용 | 클릭 구간 프레임을 통째로 버림 → 빠른 템포에서 바늘 정지 | 클릭 섞인 창은 신뢰도만 낮춤, 감지기 상태 유지 | 120 bpm 세분에서도 바늘이 흐름 |
| 연주 감지 | YAMNet (온라인, 첫 로드 수 초, 오프라인 불가) | 주기성·배음·평탄도·지속 상태기계 (attack 140 ms, 드리프트 60 ¢) | 활 바꿈에도 끊기지 않고, 백색/핑크 잡음은 0 %. 대화는 ≈90 % 포함(음악 우선 결정 — 스타카토를 잃지 않기 위해) |
| 화면 | 음이름·게이지·히스토리 | + 게이지 양 끝 ♭ ♯, 바늘 6 px, 트레이스 3 px, 띠는 .38로 뒤로 | 90 cm에서 "어느 쪽이 낮은지"를 학습 없이 읽음. 시선 순서 음이름 → 바늘 → 띠 |
| 음이름 | 도레미만 | 도레미 / C D E 설정, 선택 안 한 쪽은 작게 병기 | A현·D현이 영문이라 헷갈리던 사람에게 |
| A 듣기 | 메뉴 → 기준음 → 라 (3탭) | 튜너 헤더 'A 듣기' 1탭, 기준음(442 등) 그대로 | A현 맞추는 가장 흔한 일이 튜너를 보면서 됨 |
| 마이크 상태 | 'AI' 점 (YAMNet 로드 표시) | 무채색 점 = 켜짐, 앰버 펄스 = 멈춤, 숨김 = 꺼짐 | 초록은 '맞음' 하나의 뜻으로 남김 |
| 빈 상태 | `--` | 마이크 꺼짐이면 "MIC를 켜면 시작해요" | 왜 아무것도 안 뜨는지 말해줌 |
