# 스토어 등록 문구

Play Console 에 붙여 넣는 값. 여기서 고치고 콘솔에 옮긴다 (콘솔이 원본이 아니라 이 파일이 원본).

## 앱 이름 (30자)

```
TempoTune — 튜너·메트로놈
```

## 짧은 설명 (80자)

```
in time, in tune. 현악기 연습을 위한 튜너·메트로놈·녹음. 광고 없음, 오프라인 동작.
```

## 전체 설명

```
TempoTune 은 현악기 연습에 필요한 것만 담은 도구입니다.
튜너와 메트로놈이 한 화면에 있고, 연습을 녹음해 바로 들어볼 수 있습니다.

■ 튜너
· 콘트라베이스 E1(40Hz)부터 바이올린 고음까지
· 기준음 A = 410–466Hz (바로크 415 포함)
· 허용 오차 ±5–25 센트 조절
· 음이름 도레미 / C D E, 이명동음 함께 표시
· 최근 음정이 어떻게 흔들렸는지 화면에 남습니다

■ 메트로놈
· 2/4 · 3/4 · 4/4 · 6/8, 셋잇단 포함 세분 4종
· BPM 20–220, 재생 중에 바꿔도 끊기지 않습니다
· 화면이 꺼져도 박자가 흔들리지 않습니다
· 녹음 중에는 클릭이 무음이 되고 화면으로만 박을 보여줍니다

■ 녹음과 편집
· 구간 반복(A-B), 구간 확대, 북마크
· 0.5–1.5배속 (음높이는 그대로)
· 원하는 구간만 잘라서 WAV 로 저장·공유

■ 연습 타이머
· 켜 둔 시간이 아니라 실제로 소리 낸 시간을 잽니다
· 말소리와 잡음은 빼고 셉니다

■ 개인정보
· 마이크 입력과 녹음은 기기에서만 처리·저장됩니다
· 서버로 아무것도 보내지 않습니다
· 광고 없음, 추적 없음, 계정 없음
· 인터넷 없이도 전 기능이 동작합니다
```

## 개인정보처리방침 URL

```
https://github.com/danggeun/tempotune/blob/main/PRIVACY.md
```

**Play 심사 필수 항목**이다 — 마이크 권한을 쓰므로 없으면 반려된다.

Pages 에 따로 페이지를 만들면 원본이 둘로 갈라져 어긋난다 — 파일 하나만 둔다.

## 데이터 보안 양식 (Play Console)

| 질문 | 답 |
|---|---|
| 데이터를 수집하거나 공유하나요 | **아니오** |
| 데이터가 전송 중 암호화되나요 | 해당 없음 (전송 없음) |
| 사용자가 데이터 삭제를 요청할 수 있나요 | 앱 안에서 직접 삭제 (서버 사본 없음) |

마이크 권한은 "기기에서만 처리, 저장 안 함(녹음 버튼을 누른 경우 기기에만 저장)" 으로 설명한다.
